# Kotlin Datatypes
Since we’re aiming to become an industry-ready developer, understanding data types is less about memorizing a list and more about knowing which tool to pick for the job. In Kotlin, every type is an object, which gives us access to powerful built-in functions.

In Kotlin, We doesn't need to specify data type, Kotlin is smart to tell the datatype based on its value.
`val myNum = 5             // Int`

However, it is possible to specify the type:
`val myNum1: Int = 5       // Int`
