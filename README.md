## 📂 Project Structure
To keep this project runnable in **Android Studio**, it follows the standard Gradle structure:

* 📂 `app/src/main/java/` — **The Core:** This is where my actual Kotlin logic lives.
* 📂 `notes/` — **Deep Dives:** Detailed Markdown explanations of what I learned each day.
* 📂 `build.gradle.kts` — **Project Config:** Dependencies and build settings.

## 🛠️ How to Run This
If you want to explore the code locally:

1.  **Clone the repo:**
    ```bash
    git clone [https://github.com/shubhamraj1811/My-Kotlin-Adventure.git](https://github.com/shubhamraj1811/My-Kotlin-Adventure.git)
    ```
2.  **Open in Android Studio:**
    Select "Open an existing project" and point to the root folder.
3.  **Run:**
    Check the `MainActivity.kt` or run the unit tests (if applicable).
